# Assumptions & Data Provenance

Every cost, emission, routing, and driver-hours number in this project
traces to a source or an explicit configuration value. **Nothing here is
legally verified** — see §5.

---

## 1. Cost model (config/cost_model.yaml)

| Input | Value | Unit | Notes |
|---|---|---|---|
| Diesel price | 90.00 | INR / litre | Industry-typical, 2024. Not tied to a specific date or PSU revision. |
| HCV mileage | 3.5 | km / litre | Multi-axle >12T |
| MCV mileage | 5.5 | km / litre | 7.5–12T |
| LCV mileage | 8.0 | km / litre | <7.5T |
| Default mileage | 4.5 | km / litre | Fallback for unknown truck types |
| Driver cost | 5.0 | INR / km | Normalized from ~₹1,200/day ÷ 400 km/day |
| Toll cost | 3.0 | INR / km | Average NH toll per km |
| Maintenance | 2.0 | INR / km | Tyres + insurance + depreciation |
| Average payload | 12.0 | tonnes | Unused placeholder |

**Effective date of these values: 2024.** Replace with fleet P&L before
any operational use.

## 2. Emission factor

| Input | Value | Source |
|---|---|---|
| Diesel CO2 factor | 2.68 kg CO2 / litre | IPCC 2006 Guidelines for National Greenhouse Gas Inventories |

CO2 is **estimated from modelled fuel consumption**, not measured.
The model assumes the truck uses the configured mileage for the whole trip
and burns diesel at the default emission factor. Real-world CO2 depends on
load, gradient, speed profile, and engine condition.

## 3. Routing

| Mode | Source | Distance type |
|---|---|---|
| OSRM | Public outer.project-osrm.org (dev) | Real road distance + duration |
| Haversine fallback | Built into outing.py | Straight-line, multiplied by 1.30 to approximate road factor |

**Every API response marks which mode was used** in the source field of
route payloads ("osrm" or "haversine"). Reviewers should treat haversine
values as estimates and not as road distances.

## 4. ML training data (data/india_cities.json, ml/generate_historical_data.py)

| Input | Source |
|---|---|
| City population | UN World Urbanization Prospects 2018 + Census of India 2011 (2025 projections) |
| Industrial index | MOSPI Annual Survey of Industries, normalized 0.80–1.30 |
| Hour-of-day freight curve | NHAI toll plaza hourly aggregates (published) |
| Day-of-week curve | NHAI weekly toll volumes |
| Seasonal factor | Monsoon (Jun–Sep) reduction + festival (Oct–Nov) uptick |
| Generator | Deterministic, --seed 42 |

The 122,640-row training set is **synthetic** but structured from real
inputs. It is not observed shipment data.

Consequences:

Before any operational use:
1. Set values from the applicable Motor Vehicle rules and fleet policy.
2. Update metadata.jurisdiction and metadata.last_reviewed.
3. Set metadata.verified_against_law: true.
4. Add a test asserting the flag stays true (regression guard).

## 6. Rest facility data

**No facility rows are shipped with the project.** The CSV importer
requires source_url + source_date on every row and rejects rows
without them.

| Rule | Enforcement |
|---|---|
| Source URL required | Importer rejects rows with empty source_url |
| Source date required | Importer rejects rows with unparseable source_date |
| Coordinates must be in range | Rejected if outside ±90° / ±180° |
| erification_status must be known | One of: pending, verified, retired |
| Duplicates skipped | Same (name, latitude, longitude) |
| Path confinement | Importer only reads from data/rest_facilities/ |

**Live availability (parking spaces, dormitory beds) is not modelled.**
No public source provides it. The system never claims a facility is available.

## 8. Summary of what is *not* claimed

- Not real fuel consumption
- Not real emissions measurements
- Not live facility availability
- Not legal compliance with driving-hour rules
- Not production telematics
- Not real customer shipment data

Every one of these is stated plainly to reviewers in the README.
